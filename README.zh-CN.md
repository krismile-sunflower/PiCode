# PiCode

**跨平台的 AI 编程 Agent 指挥台 —— 任意模型、隔离并行、先审后落地。**

PiCode 是 [Pi](https://github.com/earendil-works/pi-coding-agent) 的桌面工作台。
它要解决的不是"不用开终端"，而是三件更值钱的事：让你决定哪个模型干哪种活、
让多个任务互不干扰地同时推进、让每一处改动在落地前先被你看过。

English: [README.md](README.md) · 构建与打包: [CONTRIBUTING.zh-CN.md](CONTRIBUTING.zh-CN.md)

## 为什么用 PiCode

**任意模型，按任务路由。** `models.json` 支持任何 OpenAI 兼容 / Anthropic /
Google 接口；设置 → 模型 里可以把「规划 / 编码 / 检索」分别指向不同模型，
在对应动作发生时自动切换。锁定单一供应商的客户端做不到这件事。

**隔离并行。** 新建会话时可以选择在独立的 git worktree 中工作，而不是直接改你的
工作区。同一个仓库上的两个任务不再抢同一批文件；每个隔离副本是独立路径，因此
各自拥有一个 Pi 进程 —— 它们真的在同时跑，在会话栏里随时切换。

**先审后落地。** `⌘⇧G` 打开全宽变更审阅：带行号的着色 diff、五种查看范围
（未暂存 / 已暂存 / 相对 HEAD / 相对基线分支 / 本轮改动）、按 hunk 暂存或撤销、
逐行写审阅意见后一次性交回给 Pi 修改。

**三端一致。** Windows、macOS、Linux 使用同一套打包机制与同一份功能集。

## 具体能力

- **计划 → 审阅 → 执行**：由内置扩展强制执行的只读计划模式，确认后再逐步实施。
- **可信任的权限控制**：请求确认 / 只读 / 完全访问；「本会话允许」严格限定在
  *当前会话的同一命令族*，且每一次授权决策都写入可在设置中打开的审计日志。
- **会话管理**：浏览并继续本地 Pi 会话，从任意消息分支出新会话，回退、重新生成，
  或删除某条消息及其后续。
- **`@` 文件引用**：发送的是文件*内容*，不是一串路径。
- **成本与用量**：按模型拆分，可导出 CSV。
- **`AGENTS.md` 一等公民**：应用内直接编辑随仓库走的项目指令。
- **定时任务（Automations）**：让 Pi 按计划自己跑，结果落进会话历史。

## 快速开始

安装后打开一个项目，回答首屏引导的三个问题：用哪个模型、给 Pi 多大权限、
让它直接改工作区还是改隔离副本。其余能力都可以从 `⌘K`（命令面板）和
`⌘/`（全部快捷键）里找到。

运行发布版无需额外依赖，Pi 运行时已随应用打包；从源码构建的要求见
[CONTRIBUTING.zh-CN.md](CONTRIBUTING.zh-CN.md)。

## 会话机制

PiCode 从这里读取 Pi 会话：

```text
~/.pi/agent/sessions
```

侧边栏会按项目文件夹分组展示会话。点击某个会话后，应用会直接读取对应的 JSONL 文件并渲染历史消息。该会话也会成为当前聊天目标，之后发送的新消息会追加到这个会话里，而不是只读查看历史。

无文件夹模式会使用应用自己的目录，适合用户不想选择项目文件夹、只想直接聊天的场景。

## 来源说明

本项目参考 [`deflating/tau`](https://github.com/deflating/tau) 的浏览器化 Pi UI 和 mirror 工作流。Tau 上游仍是独立项目；PiCode 在此基础上实现了 Tauri 桌面客户端、Pi 后台启动、本地会话管理和扩展安装等桌面端能力。
